How the work happens

Five moves, every time.

Same shape on a six-week engagement and a two-year platform. Only the length of each move changes.

  1. 01FrameWho it is for, what they are trying to finish, and what failure costs them.
  2. 02ExploreWide and cheap — enough options that the choice is a decision, not the first idea.
  3. 03Build the systemTokens, components and states, so screens become assemblies instead of drawings.
  4. 04ShipIn engineering's tooling, closing the gap between the file and the browser.
  5. 05WatchSession review, tickets and analytics — so the next pass is informed, not imagined.
